ORETACHI NI TSUBASA WA NAI AFTERSTORY — MAO English v1.0.0

Requires the supported Japanese retail AfterStory installation. This release
candidate checks exact source hashes, includes no game, and backs up the two
changed archives before installing. Close the game first.

WINDOWS 10 / 11
1. Extract the entire ZIP.
2. Double-click "Install AfterStory English Patch.cmd".
3. Choose the folder containing OT_AFTER.EXE.

macOS / WINE
Run:
  python3 /path/to/extracted-patch/install.py "/path/to/AfterStory/game/folder"

The installer registers MAO Gothic Q4I without overwriting an existing font
file. Restore SCRIPT.LPK and SYS.LPK from MAO-original-backup to remove the
patch. Keep saves backed up.
